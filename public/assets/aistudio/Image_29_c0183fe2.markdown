## Brand & Style

This design system expresses high-octane athletic momentum fused with behavioral gamification clarity. Designed for gym-goers, strength athletes, and functional fitness enthusiasts, the visual language balances ruthless performance tracking (inspired by elite conditioning apps) with the dopamine-driven, frictionless feedback loops of habit-forming apps.

The aesthetic fuses **Tactile High-Contrast Minimalism** and **Futuristic Cyber-Athletics**:
- **Atmosphere:** Deep obsidian carbon backdrops provide infinite depth and reduce battery draw on AMOLED panels during long workouts.
- **Energy Injection:** High-voltage fluorescent accents (Lime Volt, Blaze Orange, Hyper Cyan, Arc Purple) cut through dark canvases to direct physical action with zero visual ambiguity.
- **Tactility:** Surfaces feel touch-ready and punchy—featuring generous organic curvatures, tactile active press states, glow-infused visual telemetry, and hyper-legible condensed metrics.

## Colors

The palette relies on a stark value contrast between dense deep-space slate tones and hyper-saturated chromatic triggers:

- **Primary (`#CCFF00` - Lime Volt):** The core kinetic driver. Reserved strictly for vital workout triggers, active sets, completed status nodes, and dominant conversion points.
- **Secondary (`#FF6B00` - Blaze Orange):** The metabolic flame. Drives workout streaks, calorie burns, heart-rate max zones, and consistency rewards.
- **Tertiary (`#38BDF8` - Cyan AI):** Intelligence and recovery. Designates algorithmically generated recommendations, rest timers, mobility phases, and physiological readiness scores.
- **Accent Purple (`#8B5CF6` - Arc Violet):** Gamification currency, XP unlocks, league rank advancements, and mastery badges.
- **Surface Architecture:**
  - Base Canvas: `#0A0F1D` (Obsidian Navy)
  - Elevated Container: `#0F172A` (Slate Void)
  - Interactive Cards & Sheets: `#1E293B` (Carbon Steel)
  - Subtle Overlay / Hover: `#334155` (Muted Steel)
- **Text & Borders:**
  - Primary Text: `#F8FAFC` (Pure Velocity Off-White)
  - Muted Text: `#94A3B8` (Cool Slate)
  - Micro Borders: `rgba(204, 255, 0, 0.12)` for energized interactive cards, and `rgba(148, 163, 184, 0.08)` for passive structural frames.

## Typography

The typographic strategy balances three roles:
1. **Space Grotesk** commands headlines, set milestones, and punchy athletic counters. Its technical geometries project speed and modern grit.
2. **Plus Jakarta Sans** powers narrative interfaces, coaching guidance, and workout logs with ergonomic clarity and friendly humanist undertones.
3. **JetBrains Mono** locks down raw telemetry: reps, weights (kg/lbs), rest stopwatches, and tempo counts, preventing layout shifts when numbers tick in real-time.

Typography should always remain uppercase for tags, category pill labels, and sub-metric titles, maintaining an athletic roster aesthetic.

## Layout & Spacing

A mobile-first fluid responsive grid anchored by PWA handheld comfort:
- **Mobile Handheld Frame (Default):** Fluid 4-column layout with fixed safe margins (`margin: 1rem`) and edge-bleed bottom bars for thumb-zone execution. Interactive tap targets never drop below 48px in height.
- **Tablet / Split View (600px - 1024px):** 8-column layout. Adapts into two simultaneous workout panes: live exercise video/metrics on the left, active set logger and queue on the right.
- **Desktop Dashboard (> 1024px):** 12-column locked system (max content width 1280px) centered with `margin-desktop: 2.5rem`, providing trainer overview, program builders, and biometrics history.

Layout cadence prioritizes compact breathing room around intensive data cards while giving workout triggers expansive tap envelopes.

## Elevation & Depth

Depth is defined by dark tonal strata coupled with localized luminescence rather than traditional dropped shadows:

1. **Base Layer (Canvas):** Pure `#0A0F1D`. Passive foundation.
2. **Level 1 (Structural Modules & Inactive Cards):** Surface `#0F172A` with a 1px perimeter of `rgba(255, 255, 255, 0.05)`.
3. **Level 2 (Active Exercise Cards & Modal Sheets):** Surface `#1E293B` surrounded by a soft boundary: `border: 1px solid rgba(204, 255, 0, 0.18)` and an ambient aura: `box-shadow: 0 12px 32px -8px rgba(0, 0, 0, 0.7), 0 0 24px -4px rgba(204, 255, 0, 0.12)`.
4. **Level 3 (Sticky Kinetic Floating Action Bar):** Backdrop-filter frosted glass effect using `rgba(15, 23, 42, 0.82)` with `backdrop-filter: blur(16px)` and an electrified top rule `1px solid rgba(204, 255, 0, 0.3)`.
5. **Glow Badges & Active States:** Glowing halos with `box-shadow: 0 0 16px rgba(204, 255, 0, 0.35)` for primary interactions, and `box-shadow: 0 0 16px rgba(255, 107, 0, 0.35)` for active streaks.

## Shapes

The interface embraces oversized organic radii to inject approachability into an otherwise intense athletic palette:
- **Default Elements:** 0.5rem (`rounded`) for input counters, set pills, and micro utility triggers.
- **Core Cards & Action Tiles:** 1rem to 1.5rem (`rounded-2xl` equivalent) creating clean containment for complex workout data.
- **Primary CTAs, Workout Stage Trackers, and Badges:** Fully rounded capsule/pill architecture (`rounded-full`) delivering immediate tactile affordance and thumb friendliness.

## Components

### Buttons
- **Primary Kinetic CTA ("Iniciar Treino", "Completar Série"):** High-contrast Lime Volt (`#CCFF00`) solid fill with bold slate text (`#0A0F1D`). Fully pill-shaped (`border-radius: 9999px`), min-height 54px. Active state applies a scale transformation (`scale: 0.97`) and an intensified Lime glow.
- **Secondary Athletic Button:** `#1E293B` surface with a crisp 1px border `rgba(204, 255, 0, 0.3)` and `#F8FAFC` label text.
- **Streak & Gamification CTA:** Fiery gradient or solid `#FF6B00` fill with white text, utilized for streak saves, challenge acceptance, and celebration triggers.

### Chips & Intensity Tags
- **Micro-Badges (Tags de Intensidade):** 6px vertical padding, 12px horizontal padding. JetBrains Mono font (`label-mono-sm`).
  - *Hardcore / RPE 9-10:* Background `rgba(255, 107, 0, 0.15)`, text `#FF6B00`, border `1px solid rgba(255, 107, 0, 0.4)`.
  - *Optimal / AI Suggested:* Background `rgba(56, 189, 248, 0.15)`, text `#38BDF8`, border `1px solid rgba(56, 189, 248, 0.4)`.
  - *XP Multiplier:* Background `rgba(139, 92, 246, 0.15)`, text `#C4B5FD`, border `1px solid rgba(139, 92, 246, 0.4)`.

### Workout Cards
- Built using `#1E293B` background with `1.25rem` corner radius.
- Includes high-contrast exercise imagery or looping muscle SVG wireframes framed with subtle dark gradient vignettes.
- Active card showcases a dynamic neon edge (`border-left: 4px solid #CCFF00`).

### Interactive Metric Loggers & Inputs
- **Weight & Rep Counters:** High-legibility stepper modules with large mono numbers (`metric-huge`) positioned between tactile circular `+` and `−` increment buttons with quick-tap haptic feedback emulation.
- **Checkboxes & Set Log Circles:** 36px circular targets. Unchecked: `border: 2px solid #334155`. Completed: Snap fills with `#CCFF00` with a dark `#0A0F1D` checkmark icon and an instant radial glow ping.

### Gamification & Streak Modules
- **Streak Flame Card:** `#0F172A` housing with flame icon infused with ambient `#FF6B00` halo, tracking days with connected geometric progress pips.
- **XP Level Progress Bar:** 10px high rounded track in `#1E293B` filled with an electrified gradient from `#8B5CF6` to `#38BDF8`.
